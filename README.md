# Sound_Pillow_V1

Sound Pillow is an 12 key sounboard with aa rotarty encoder 7 sk mini-e and uses kmk firmware

Features:

12 keys
EC11 Rotary encoder for Volume
7 sk mini-e for a little disco
and aa case in the shape of a pillow 

Cad Model:

the case uses glue to fit everything together at the final stage 
it haas 2 sepaaretly printed pieces the bottom where the pcb slides in to and one top hat you put ovr your key

Firmware Overview

This hackpad uses kmk firmware for everything 
the rotary encoder changes thee volume and i didn't use the button
The 12 keys act as f13-f24 and i use https://www.voicemod.net/ as the software  so i can use the macropad as a soundboard  in discord 
and the leds are there for a little disco

Bom 

-12x Cherry MX Switches
12x DSA Keycaps
-2x M3x16mm SHCS Bolts
-5x 1N4148 DO-35 Diodes.
-7x sk mini-e LEDs
-1x EC11 Rotary Encoder
-1x XIAO RP2040
-1x Case (2 printed parts)

and if you're wondering why there is a hole in the top right of the case that's so you can add an acrylic plate or just watch the components
